This file covers the two bundled JavaScript files in this directory.

`assets/bugbottle.js` is the official one-script-tag build of the bugbottle
library (https://github.com/mahope/bugbottle), copied here unmodified.

`assets/bugbottle-screenshot.js` is the same library's `bugbottle/html-to-image`
entry bundled together with html-to-image (https://github.com/bubkoo/html-to-image)
by `bin/build-screenshot-bundle.sh`, which records the exact versions and the
exact esbuild command. It is loaded only when the Screenshots setting is on.
